# CAPS 0.6.0 release candidate

Fresh installations receive Astra Low interactive defaults and Luna Max worker
defaults. Upgrades preserve explicit settings. The bounded cascade permits one
useful Luna correction, one Sol Extra High attempt, and one separate Astra
Medium worker attempt, then stops. Missing access or evidence does not escalate.

The worker ceiling is six per root, excluding the lead, with no automatic
nesting and one writer per overlapping file set. Receipts retain legacy
compatibility while including lead acceptance and later corrections. Learning
is recommendation-only and reports unavailable subscription usage as unknown.

Local tests, installed behavior, scheduled execution, and publication remain
separate proof states. No claim that these defaults are proven cheaper is made.
Activation needs exact target diffs and drift-safe backup/rollback. Public
release can proceed to approval after functional verification; no observation
week or private digest dependency is required.
