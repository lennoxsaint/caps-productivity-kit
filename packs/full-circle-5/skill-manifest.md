# Full Circle 5.0 Placeholder Skill Manifest

This placeholder pack does not require any private skill or connector.

## Required

- None.

## Optional

- Browser or app automation for visual QA.
- Calendar, community, or document connectors when the target workspace allows
  them.
- Review tooling that can scan for private material before public sync.
- A student-owned content review script that can prepare draft posts from a
  source library without publishing them.
- A student-owned scheduling tool in dry-run or review mode.

## Safety

Optional tools must not send messages, publish content, change production data,
or expose private cohort information unless the target project instructions and
latest user request explicitly authorize that action.

For daily content review, the default mode is prepare-only. External scheduling
requires same-day human approval and a live readback from the student's chosen
scheduling tool.
