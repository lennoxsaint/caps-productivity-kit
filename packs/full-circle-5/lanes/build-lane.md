# Lane: Build Cohort Kit

Use this as a bounded build lane for a public-safe cohort-launch artifact.

## Objective

Build one installable or copyable artifact for the cohort operating system.

## Allowed Content

- Generic prompts.
- Generic checklists.
- Public-safe setup docs.
- Placeholder examples.

## Not Allowed

- Member names.
- Private thread IDs.
- Paid cohort lesson content.
- Private community, payment, calendar, or launch-proof details.
- Claims that Codex can automatically pin threads unless the runtime proves it.

## Output

Return:

- Files changed.
- Verification output.
- Public-safety checks.
- Remaining blockers.
- public_repo_sync_recommendation: yes/no.
