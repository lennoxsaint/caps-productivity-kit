# Full Circle 5.0 Placeholder Prompt Schedule

This schedule is generic. Replace it only with public-safe material.

## Morning Mission Control

- Read the project instructions.
- Name active lanes.
- Name blockers.
- Pick the highest-leverage next action.
- Route one bounded outcome at a time.

## Build Lane

- Own one concrete artifact.
- Keep source material public-safe.
- Return files changed and verification output.

## Daily Content Review

- Run around 8:00 local time.
- Read the student's source library, brand notes, feedback ledger, CTA policy,
  and prior review artifacts.
- Prepare a review packet with draft posts and validation output.
- Keep the output in draft/review state until same-day human approval.
- Do not post, schedule, publish, or write production data.

## QA Lane

- Verify the user/member-facing flow in the target environment.
- Separate local proof from live proof.
- Report exact blockers.

## Review Lane

- Check for private material before any public sync.
- Check that no pack claims automatic thread pinning unless runtime tools prove it.
- Recommend whether the public kit should receive the pattern.

## Close

- Capture shipped work.
- Capture blockers.
- Recommend unpin-ready lanes.
- Backfeed reusable CAPS patterns.
