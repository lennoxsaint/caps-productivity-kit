# Lane Template: Mission Control

Use this for the conductor lane of a pack.

## Objective

Coordinate active lanes, keep proof current, and route bounded work without
duplicating effort.

## Start

1. Read project `AGENTS.md`.
2. Read this pack's `pack.yaml` and `setup.md`.
3. Name active lanes, blockers, and unpin candidates.
4. Route only the next bounded outcome.

## Output

Return:

- Active lanes.
- Current blocker.
- Highest-leverage next action.
- public_repo_sync_recommendation: yes/no.
