# Lane Template: Worker

Use this for a bounded worker lane inside a pack.

## Objective

Complete the assigned outcome with proof.

## Inputs

- Source conductor context packet.
- Target workspace.
- Allowed files or surfaces.
- Verification command or proof path.
- Stop conditions.

## Output

Return:

- Status.
- Files changed or inspected.
- Verification output.
- Blockers.
- public_repo_sync_recommendation: yes/no.
