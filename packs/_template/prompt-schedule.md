# Example Prompt Schedule

Use this to define when each prompt should run.

## Daily Start

- Open the mission-control lane.
- Read current project instructions.
- Name active lanes and blockers.
- Choose the highest-leverage next action.

## During Work

- Route implementation to `BUILD ...`.
- Route verification to `QA ...`.
- Route risk review to `REVIEW ...`.
- Keep proof attached to the lane that owns the claim.

## Daily Close

- Capture what shipped.
- Capture what slipped.
- Recommend unpin-ready lanes.
- Name remaining blockers.
